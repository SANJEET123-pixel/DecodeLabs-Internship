# DecodeLabs Project 2 – Exploratory Data Analysis

## 📊 Project Overview

This project was completed as part of the DecodeLabs internship program.

The objective of this project is to perform Exploratory Data Analysis (EDA) on a provided e-commerce order dataset and identify important patterns, trends, and potential outliers.

## 🎯 Objectives

- Understand the structure of the dataset
- Calculate basic statistical measures
- Analyze product-wise sales performance
- Identify revenue trends over time
- Detect potential outliers using the IQR method
- Summarize important findings from the analysis

## 📁 Dataset

The dataset contains e-commerce order information, including fields such as:

- Order ID
- Customer ID
- Date
- Product
- Category
- Quantity
- Unit Price
- Payment Method
- Order Status
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

## 🛠️ Tools Used

- Microsoft Excel
- Excel formulas
- Excel charts
- Exploratory Data Analysis
- IQR method for outlier detection

## 🔍 Analysis Performed

### 1. Basic Statistics

The following metrics were calculated:

- Total Orders
- Total Quantity Sold
- Total Revenue
- Average Order Value
- Median Order Value
- Average Unit Price
- Average Items in Cart

### 2. Product Analysis

Product-wise revenue and quantity sold were analyzed to identify the highest- and lowest-performing products.

### 3. Revenue Trend Analysis

Revenue was analyzed across different years to identify changes and trends over time.

### 4. Outlier Analysis

The Interquartile Range (IQR) method was used to identify potential outliers in order values.

## 📈 Key Findings

- The dataset contains **1,200 orders**.
- Total revenue generated was **₹12,64,761.96**.
- Total quantity sold was **3,535 units**.
- The average order value was **₹1,053.97**.
- The median order value was **₹823.62**.
- **Chair** generated the highest revenue among the products at **₹1,95,620.11**.
- **Phone** generated the lowest revenue among the products at **₹1,51,722.39**.
- Annual revenue decreased from **₹5,52,643.24 in 2023** to **₹4,80,235.87 in 2024** and **₹2,31,882.85 in 2025**.
- The IQR method identified **8 potential outliers** in order values.

## 📊 Visualizations

The Excel workbook includes visualizations for:

- Revenue by Product
- Revenue Trend Over Time

These visualizations help communicate the major patterns identified during the analysis.

## 💡 Conclusion

The exploratory data analysis provided useful insights into overall sales performance, product-wise revenue differences, time-based trends, and potential outliers.

The analysis demonstrates how Excel can be used to organize, analyze, visualize, and interpret real-world sales data.
