# DecodeLabs Data Analytics – Project 1
## Data Cleaning & Preparation

### 📌 Project Overview

This project is part of my Data Analytics internship at DecodeLabs.

The main objective of this project is to clean and prepare a raw customer sales dataset by identifying and correcting common data-quality problems.

The project focuses on data integrity and preparation before the data is used for further analysis.

---

## 🎯 Objectives

The main objectives of this project are:

- Identify and handle missing values
- Identify and remove duplicate Customer IDs
- Correct inconsistent date formats
- Identify and handle invalid dates
- Clean inconsistent text values
- Convert incorrectly formatted numerical values
- Validate the cleaned dataset
- Export the final cleaned dataset
